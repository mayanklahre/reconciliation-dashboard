# v1.0.0 release notes

**Release notes prepared on 19 October 2026.**

## Shipped
- Local CSV/XLSX/XLS upload and valuation reconciliation workflow.
- Published-PDF collection, PDF extraction, date/series matching, row-level variance status, and timestamped JSON audit logs.
- React frontend, FastAPI backend, local setup, tests, documentation, and handover notes.

## Known limits
- Built and delivered as a repository; not hosted or deployed by the developer.
- Source PDF layouts and series names can change; analyst review remains necessary.
- Authentication and production operations are out of scope.

## Handover
Source repository, setup instructions, test command, risk/quality documentation, and maintenance notes are included. Client files and generated audit logs must remain out of Git.
